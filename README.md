# Webbles

Автономная система исправления ошибок в чужом коде. Находит ошибки
анализаторами, генерирует минимальные фиксы и **проверяет каждый патч против
инварианта целостности**: изменение не принимается, если оно потеряло,
задублировало или исказило существующие символы, либо если откат не вернул
файл в исходное состояние.

Работает офлайн на локальной LLM (llama.cpp + Qwen-Coder) — код никуда не
уходит. Поддерживает и внешние API (ключ в `.env`).

## Ключевые идеи

- **Безопасность прежде всего.** Решение принять патч выносят детерминированные
  проверки (символьная регрессия, net-delta, синтаксис), а не языковая модель.
  На верификационных прогонах — 0 небезопасных изменений.
- **Изолированная песочница.** Работа идёт на копии; в проект пользователя не
  попадает ничего, кроме бэкапа.
- **Rule-based приоритетнее LLM.** Детерминированный фикс всегда предпочтительнее
  генерации моделью.
- **Мультиязычность.** Python (зрелый), Rust / C++ / C# (ранняя стадия) —
  единый пайплайн.

## Как работает

```
Analyze → Classify → Prioritize → Generate → Apply → Validate → Review
        → Decide (ACCEPT / REJECT / NEEDS_REVIEW) → аудит → доставка
```

Анализаторы: flake8, mypy (Python), cppcheck / clang-tidy (C++), clippy (Rust),
Roslyn (C#), semgrep (безопасность).

## Интерфейс

`studio.py` — десктоп-приложение (Eel): выбор папки проекта, запуск починки,
живой прогресс и «до / после» по каждому файлу с объяснением.

## Запуск

```bash
pip install -r requirements.txt

# LLM: либо внешний API (ключи в .env, см. .env.example),
# либо локальный сервер llama.cpp (OpenAI-совместимый) — настройки в webles_config.json

python studio.py                      # десктоп-интерфейс
python run_agent.py <путь-к-проекту>  # из командной строки
```

## Статус

Прототип с проработанным ядром безопасности. Python-ветка зрелая; Rust / C++ /
C# — на более ранней стадии, тот же процесс. Комментарии в коде — на русском.
